# Frontend: Прогноз ціни ноутбука

HTML, CSS та JavaScript без фреймворків, CDN і збирання. Сторінки та ресурси віддає наявний FastAPI: `/`, `/analytics`, `/static/*`; документація — `/docs/`.

## Запуск із кореня проєкту

За встановлених backend-залежностей і наявних артефактів моделі:

```powershell
.\venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

Відкрити `http://localhost:8000/`. Для збереження історії потрібна налаштована PostgreSQL; прогнозування працює й без доступної БД. Не відкривати HTML через `file://`: форма використовує API того самого сервера.

Окремий QA-запуск із реальною моделлю, без читання `.env` і звернень до БД:

```powershell
.\venv\Scripts\python.exe frontend/tests/preview.py
```

Адреса QA: `http://127.0.0.1:8765/`. Зупинка — `Ctrl+C`. Контейнери не потрібні. Не використовувати цей допоміжний режим для збереження історії.

## Налаштування й модулі

- `config.js` — назва, `contacts.author/group/email/phone`, маршрути, теми та тайм-аут HTTP (30 секунд). Порожні контакти показуються як «Не вказано»; заповнені email/телефон стають посиланнями.
- `preferences.js` — застосування теми до першого відображення, збереження теми й руху в `localStorage`, системний `prefers-reduced-motion`. Типова тема — темна. На аналітиці рух завжди вимкнений.
- `form.js` — метадані всіх 15 полів `LaptopInput`, побудова списків із `GET /api/options`, валідація та серіалізація.
- `api.js` — HTTP, тайм-аут, нормалізація помилок та перевірка формату прогнозу.
- `storage.js` — перевірений знімок останнього успішного запиту в `sessionStorage`; строк зберігання — поточна вкладка. Невдалі запити й очищення форми його не замінюють.
- `script.js` — загальні компоненти, форма, результати, метрики й аналітика. Особисті дані не потрібні для прогнозу.

Порожні `opsys` та `screen_height` пропускаються в JSON; прапорці передаються як boolean. Сервер сам обчислює бренди CPU/GPU та їхню пару. Жорсткі числові межі взяті з `backend/schemas.py`; `numeric_ranges` — лише довідкові межі навчальних даних. Гривня має код **UAH**. Ціна й типовий діапазон надходять лише з `/api/predict`, а джерело діапазону та метрики — з `/api/model-info`.

Готові шість PNG з `img/` показують загальне оцінювання, а не індивідуальне пояснення. API не надає внесків ознак конкретного прогнозу або кількох паралельних прогнозів. До першого успішного запиту особистий розділ аналітики прихований. Контакти автор заповнює сам у `config.js`.
